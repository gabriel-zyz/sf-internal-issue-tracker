# Internal Issue Tracker (Salesforce LWC App)

A simple internal issue tracker app built using Salesforce Lightning Web Components (LWC) and Apex.

## Features
- Create, edit, and delete issues
- Filter by status and priority
- Built-in dashboard using Salesforce Reports
- Neat UI, ready for demo or extension

## Tech Stack
- Apex (Server-side logic)
- Lightning Web Components (LWC)
- Salesforce No-Code Dashboards
- Git + VS Code

## Setup Instructions
1. Create a Salesforce Developer Org
2. Deploy the custom object `Issue__c` with fields
3. Push LWC components and Apex classes
4. Add to a Lightning App Page
